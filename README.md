This repository holds a one-sentence entry for the make.fun bounty “One Sentence for a Traveler from 1800”, which caps entries at 200 characters. The submitted sentence reads: “Picture every town's letters, books and talk carried on one road no eye can see: a note you write at breakfast is read across the sea before supper, and every book ever printed lies open to you.” — 194 characters in total, framed entirely in things a reader from 1800 already knows: letters, roads, breakfast and supper.

Running `main.ts` writes that exact sentence, with nothing added, to `entry.txt` inside the output directory. Before writing, the program checks its own sentence against the gate: between 1 and 200 characters, confined to a single line, and not whitespace-only. The sentence survived an adversarial comparison against five other candidates and won on the opening judging criteria.

## Running locally

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
