A single line for make.fun's “One Sentence for a Traveler from 1800” bounty (200 characters at most): “Picture every town's letters, books and talk carried on one road no eye can see: a note you write at breakfast is read across the sea before supper, and every book ever printed lies open to you.” The line is 194 characters. A tiny deterministic Node program writes exactly that line to the entry file and guards the gate itself: 1–200 characters, a single line, never only whitespace. It was picked by an adversarial criteria critique over 6 candidates, strongest on the judge's first criteria in order.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
